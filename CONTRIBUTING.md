# Contributing

The repository is contract-only and does not yet accept implementation work.
Discuss contract changes before writing code. A change must preserve the
host-authoritative security boundary, name its data and network exposure, add
verification for failure paths, and record compatibility consequences.

Canonical development occurs on Forgejo. GitHub is a one-way public mirror;
GitHub pull requests are not canonical. No license has been selected, so no
permission to copy, modify, or redistribute is implied.
