# Provenance

scripts/build-artifact.sh emits provenance.json beside each binary. A release build rejects a dirty tree, captures an exact commit/tree, exports that immutable commit, and records the complete hermetic Go environment including GOAMD64=v1, binary hash, SBOM hash, legal-inventory hash, toolchain hash, and builder path. SHA256SUMS binds every archive file, including all third-party legal texts, upgrade, and rollback instructions; the deterministic archive binds SHA256SUMS. The archive SHA-256 is emitted as a portable <archive>.sha256 sidecar whose filename field is the archive basename, because embedding it would be self-referential. Before the archive and sidecar become visible in the output directory, the builder validates the gzip stream, extraction, executable version, embedded checksums, and external checksum. Exact version-command outputs and executable hashes are verified against docs/release/toolchain.json.

Provisional development artifacts require explicit GOTTH_EXTENSION_ALLOW_DIRTY_EVIDENCE=1 and honestly record source_dirty=true and source_tree=dirty-worktree. Release admission uses the clean default against a final exact commit and independently verifies the emitted archive digest. Provenance is unsigned local evidence until an authorized release process signs and publishes it.
