# Workflow

`workflow.toml` is canonical. A planned contract is not an implementation,
artifact, release, deployment, or compatibility claim. The exact published
`gotth-extensions v1.0.0` and `gotth-sdk v1.0.0` modules are the future
implementation baseline only. `translation.contract` remains `planned`,
and its `depends_on` list remains empty until implementation is explicitly
activated. No runtime, test, generated-control, or artifact evidence is
recorded here.
